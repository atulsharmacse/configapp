# Config Studio by Network Kings

The offline network lab simulator for [config.nwkings.com](https://config.nwkings.com).

**Download and install guide: https://config.nwkings.com/download**

Installers are in [Releases](https://github.com/atulsharmacse/configapp/releases/latest): Windows (.exe), macOS Apple Silicon and Intel (.dmg), Linux (.AppImage, .deb).
